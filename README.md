# 🐎 Кінний клуб «Золоті Копита»

Вебсайт-візитівка кінноспортивного комплексу. Презентує послуги, напрямки тренувань, дитячі програми та контактну інформацію. Всі дані завантажуються асинхронно з локального JSON-файлу, є фільтрація карток, інтерактивні лайки, бургер-меню та валідація форми зворотного зв’язку.

## Функціонал

- 🎴 **Динамічні картки послуг** – завантажуються з `data.json` за допомогою `async/await`.
- 🔍 **Фільтрація за категоріями** – «Верхова їзда», «Виїздка», «Дитячі групи» або всі одразу.
- ❤️ **Лайки** – інтерактивна кнопка «серце» з анімацією та зміною лічильника.
- 📱 **Адаптивний дизайн** – сітка карток 4-3-2-1 колонки, мобільне бургер-меню.
- 📝 **Форма зворотного зв’язку** – валідація на стороні клієнта (телефон у форматі +380XXXXXXXXX).
- ⏳ **Індикатор завантаження** – сповіщає користувача під час отримання даних.
- 🧭 **Прокручування до розділів** – плавний скрол за якірними посиланнями.
- ⚡ **Прогресивне покращення** – коректна робота навіть без JavaScript (хоча динамічні картки не з’являться).
